# Glossary

## Overview

Plain-language definitions for terms you will see in {{brandName}} documentation and the product interface.

## Purpose

Build a shared vocabulary across admins and everyday users.

## Prerequisites

None.

---

## A

### Activity Log

A record of user and system actions—logins, uploads, invites, connector syncs, exports—for auditing and troubleshooting. See [Activity Logs](/docs/user-guide/activity-logs).

### AI Chat

A conversational interface that answers questions using documents in your current workspace, with citations to source files. See [AI Chat](/docs/user-guide/ai-chat).

---

## C

### Citation

A link from an AI Chat answer to the specific document passage used to generate that answer. Always verify citations before making decisions.

### Classify (Classification)

The pipeline stage where {{brandName}} assigns document type, tags, or categories after text extraction.

### Company Admin

Organization-wide administrator with access to all workspaces, org settings, and billing (SaaS). See [Users and Roles](/docs/user-guide/users-and-roles).

### Connector

An integration that automatically ingests documents from Email, SFTP, or SharePoint into a workspace. See [Connectors](/docs/user-guide/connectors).

---

## D

### Dashboard

The home screen showing workspace metrics, recent activity, and quick actions. See [Dashboard](/docs/user-guide/dashboard).

### Document Pipeline

The automated sequence: upload → ingest → extract → classify → ready for search and AI Chat. See [Document Pipeline](/docs/user-guide/document-pipeline).

### Document Vault

The Documents section where workspace files are stored, searched, and previewed. See [Documents](/docs/user-guide/documents).

---

## E

### Extract (Extraction)

Pulling text, tables, and metadata from a file; includes OCR for scanned images.

---

## G

### Group

{{brandName}} term for a **workspace**—a isolated container for documents, users, and settings. Groups and workspaces mean the same thing.

### Group Admin

Workspace administrator who manages users, connectors, and documents for assigned Groups. Also called **workspace admin**.

---

## I

### IDP (Intelligent Document Platform)

The category of software {{brandName}} belongs to—platforms that ingest documents and apply AI for search, extraction, and understanding.

### Ingest (Ingestion)

Registering and preparing an uploaded or connector file for extraction in the pipeline.

---

## O

### Organization (Org)

Your company's top-level {{brandName}} account containing users and workspaces.

### Org Settings

Company-wide configuration managed by Company Admins. See [Org Settings](/docs/user-guide/org-settings).

---

## R

### RAG (Retrieval-Augmented Generation)

The technique AI Chat uses: retrieve relevant document snippets, then generate an answer grounded in those sources.

### Report

An export of workspace data or metrics as CSV, PDF, or XLSX. See [Reports](/docs/user-guide/reports).

---

## S

### Search User

Standard role for searching documents, using AI Chat, and downloading reports within assigned workspaces.

### SFTP Connector

Automated intake from an SFTP server folder on a schedule.

### SharePoint Connector

Automated sync from a Microsoft SharePoint site or library.

---

## W

### Workspace

A team or project area in the UI; called a **Group** in {{brandName}} platform terminology. See [Workspaces](/docs/user-guide/workspaces).

### Workspace Switcher

The top navigation control for changing the active workspace. See [Workspace Switcher](/docs/user-guide/workspace-switcher).

---

## Expected Results

You understand key {{brandName}} terminology used across the documentation.

## Tips

When docs say "Group" and the UI says "Workspace," they refer to the same thing.

## Best Practices

Share this glossary in onboarding slides for new hires.

## Common Mistakes

Assuming "Group" means a user group like an email distribution list—it is a document workspace.
