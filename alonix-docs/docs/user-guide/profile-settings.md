# Profile Settings

## Overview

**Profile Settings** is where you manage your personal account—display name, email (where permitted), password, avatar, and preferences such as time zone or notification options.

## Purpose

Keep your identity accurate for activity logs and maintain secure credentials without admin involvement for routine changes.

## Prerequisites

- Active Alonix account
- Logged in

## Step-by-Step Instructions

### 1. Open Profile Settings

1. Click your **avatar or name** in the top navigation.
2. Select **Profile** or **Profile Settings**.

[Screenshot – Profile settings page with name, email, and change password sections]

### 2. Update display name

1. Edit **Full name** or **Display name**.
2. Save changes.
3. Your new name appears in activity logs and user lists.

### 3. Change password

1. Click **Change password**.
2. Enter current password.
3. Enter and confirm new password meeting strength rules.
4. Save and log in again if prompted.

For forgotten passwords, use **Forgot password** on the login page — [Login Problems](/docs/troubleshooting/login-problems).

### 4. Update avatar (optional)

1. Click profile photo placeholder.
2. Upload an image or choose initials.
3. Save.

### 5. Set preferences

Adjust available options:

- Time zone
- Email notifications (invites, pipeline failures if enabled)
- Language or date format (if supported)

### 6. Log out

Use **Log out** from the profile menu on shared devices.

## Expected Results

- Profile changes saved and visible immediately or after refresh.
- Password change invalidates old credentials.
- Preferences affect how dates and notifications display.

## Tips

- Use a password manager for strong unique passwords.
- Keep display name aligned with corporate directory for easier admin support.

## Best Practices

- Change password immediately if you suspect compromise.
- Do not reuse passwords from other systems.
- Log out on shared kiosks and conference room PCs.

## Common Mistakes

- Changing email without admin approval when org policy locks email to SSO domain.
- Saving weak passwords that fail policy without reading error messages.
- Leaving sessions open on public computers.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Cannot change email | Contact Company Admin—may be SSO-managed. |
| Password rejected | Follow on-screen strength requirements. |
| Avatar upload fails | Use JPG/PNG under size limit. |
