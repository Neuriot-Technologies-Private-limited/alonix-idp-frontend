# Who Should Use {{brandName}}?

## Overview

{{brandName}} is built for anyone who works with large volumes of documents and needs fast, reliable answers—not just IT teams. From operations and finance to legal and customer support, {{brandName}} helps people find information, collaborate in workspaces, and reduce manual document handling.

## Purpose

This guide helps you identify whether {{brandName}} fits your needs and which features matter most for your role. Use it when evaluating {{brandName}} for your team or onboarding new colleagues.

## Prerequisites

- Basic familiarity with web applications (browser, login, file upload)
- An understanding of your team's document workflows (optional but helpful)

## Step-by-Step Instructions

### 1. Match your team to {{brandName}} use cases

| Team | Typical use |
|------|-------------|
| **Finance & Accounting** | Invoices, statements, audit trails, CSV/PDF reports |
| **Legal & Compliance** | Contracts, policies, classification, activity logs |
| **Operations** | SOPs, vendor documents, connector-based intake |
| **HR** | Employee records, onboarding packets (with proper access controls) |
| **Customer Support** | Policy lookup via AI Chat, quick document retrieval |
| **IT / Platform** | User management, connectors, org settings |

### 2. Identify your likely role

**Company Admin**

- Sets up the organization, manages billing (SaaS), and oversees all workspaces.
- Best for: IT leads, operations directors, founders.

**Group Admin (Workspace Admin)**

- Creates and manages workspaces, invites users, configures connectors, uploads documents.
- Best for: team leads, department managers, project owners.

**Search User**

- Searches documents, uses AI Chat, downloads reports, views activity within assigned workspaces.
- Best for: analysts, specialists, support staff, general team members.

### 3. Decide what you need on day one

| Need | Where to start |
|------|----------------|
| Store and search files | [Documents](/docs/user-guide/documents) |
| Ask questions in plain language | [AI Chat](/docs/user-guide/ai-chat) |
| Automate file intake | [Connectors](/docs/user-guide/connectors) |
| Track who did what | [Activity Logs](/docs/user-guide/activity-logs) |
| Export data for stakeholders | [Reports](/docs/user-guide/reports) |

## Tips

:::note SaaS vs self-hosted
Billing and some org-level settings appear only on SaaS deployments. Self-hosted customers may manage licensing outside the app.
:::

- **Search Users** can be productive within minutes after an invite—no setup required.
- **Group Admins** should plan workspace structure before inviting large teams. See [Workspace Governance](/docs/best-practices/workspace-governance).

## Best Practices

- Start with a pilot workspace and 3–5 power users before rolling out company-wide.
- Pair a **Group Admin** with a **Search User** during onboarding so both setup and daily-use perspectives are covered.
- Document your naming conventions early (workspace names, tags, folders) using [Document Organization](/docs/best-practices/document-organization).

## Common Mistakes

- Giving everyone Company Admin access "just in case" — use the least privilege needed. See [Users and Roles](/docs/user-guide/users-and-roles).
- Rolling out connectors before testing manual uploads — validate the pipeline with a small batch first.
- Skipping security review for sensitive data — read [Security and Sensitivity](/docs/best-practices/security-sensitivity).

## Troubleshooting

| Question | Answer |
|----------|--------|
| I only need read/search access | Ask for **Search User** in the relevant workspace(s). |
| I manage multiple departments | Request **Group Admin** on each workspace, or **Company Admin** for org-wide control. |
| We need API integration | See the [Developer Setup](/docs/developer/setup) for technical documentation. |
