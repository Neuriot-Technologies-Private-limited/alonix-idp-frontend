# Tutorial: Generate a Report

## Overview

Export a document inventory report for your workspace—a common task for audits and team standups.

## Purpose

Learn the report builder flow end-to-end with a practical example.

## Prerequisites

- Documents in workspace (upload tutorial completed)
- Report permission for your role
- Date range in mind (e.g., last 30 days)

## Step-by-Step Instructions

### Step 1: Open Reports

1. Select workspace.
2. Click **Reports**.

### Step 2: Choose Document Inventory

Select template matching document list export (name may vary by deployment).

[Screenshot – Report configuration with date range and format selector]

### Step 3: Set filters

1. Start date: 30 days ago.
2. End date: today.
3. Status: Complete (optional).

### Step 4: Export CSV

1. Format: **CSV**.
2. Click **Generate**.
3. Download when ready.

### Step 5: Validate in spreadsheet

Open CSV in Excel or Sheets:

- Row count matches expectation.
- Filenames and dates look correct.
- Workspace name in export metadata if included.

### Step 6: Try PDF (optional)

Repeat with **PDF** for a presentation-friendly layout.

## Expected Results

Downloadable CSV/PDF reflecting filtered workspace documents.

## Tips

CSV best for analysis; PDF best for executives.

## Best Practices

[Security and Sensitivity](/docs/best-practices/security-sensitivity) before emailing exports.

## Common Mistakes

Exporting all statuses when leadership only wants Complete documents.

## Troubleshooting

Empty export—widen date range or check workspace.
