# Tutorial: Upload a Document

## Overview

Learn by doing: upload a real file, watch the pipeline, and confirm search and preview work in your workspace.

## Purpose

Build confidence with the most common daily action in {{brandName}}.

## Prerequisites

- Workspace access
- Sample PDF or DOCX (non-sensitive recommended for first try)
- [Workspace Switcher](/docs/user-guide/workspace-switcher) set correctly

## Step-by-Step Instructions

### Step 1: Prepare your file

Rename for clarity: `Tutorial_Sample_Invoice.pdf`

### Step 2: Upload

1. Open **Documents**.
2. Click **Upload** or drag the file onto the page.
3. Wait for upload progress to finish.

[Screenshot – Upload progress bar completing]

### Step 3: Watch pipeline status

1. Find your file in the list.
2. Note status: `Queued` → `Processing` → `Complete`.
3. Refresh if needed after 1–2 minutes.

### Step 4: Open preview

1. Click the document name.
2. Confirm extracted text appears in preview pane.

### Step 5: Search

1. Return to document list.
2. Search a unique word from the file.
3. Confirm your document appears in results.

## Expected Results

Upload succeeds, pipeline completes, search and preview work.

## Tips

Text PDFs complete faster than scanned images.
