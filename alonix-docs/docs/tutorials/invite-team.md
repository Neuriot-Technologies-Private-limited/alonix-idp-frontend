# Tutorial: Invite Your Team

## Overview

Group Admins and Company Admins use this workflow to bring teammates into a workspace with **Search User** or **Group Admin** roles.

## Purpose

Onboard colleagues so they can search, chat, and collaborate without over-provisioning admin access.

## Prerequisites

- Group Admin or Company Admin role
- Teammate email addresses
- Target workspace created — [First Workspace](/docs/tutorials/first-workspace)

## Step-by-Step Instructions

### Step 1: Choose roles

| Teammate needs | Assign |
|----------------|--------|
| Search and chat only | Search User |
| Manage users, connectors, uploads | Group Admin |

### Step 2: Send invitation

1. Select correct workspace in switcher.
2. Open **Users** → **Invite user**.
3. Enter email.
4. Select role and workspace (if not pre-filled).
5. Click **Send invitation**.

[Screenshot – Invite user dialog with email and role fields]

### Step 3: Teammate accepts

They should:

1. Open invitation email.
2. Click **Accept invitation**.
3. Log in or sign up.
4. Verify workspace in switcher.

### Step 4: Confirm access

1. Refresh **Users** list—status shows Active or Accepted.
2. Ask teammate to open **Documents** and **AI Chat**.

### Step 5: Repeat for the team

Batch invites during a rollout meeting so support is available live.

## Expected Results

Invitees access workspace with correct role and menus.

## Tips

Default to Search User; promote to Group Admin only when needed.

## Best Practices

[Manage Users](/docs/tutorials/manage-users) for ongoing access reviews.

## Common Mistakes

Wrong workspace selected in invite dialog.

## Troubleshooting

Invite not received—check spam; resend from Users page.
