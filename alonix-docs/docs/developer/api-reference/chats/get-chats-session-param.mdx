# GET /chats/session/\{sessionId\}

**[Try in API Playground](/api-playground?path=%2Fchats%2Fsession%2F%7BsessionId%7D&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/chats/session/{sessionId}` |
| **Tag** | Chats |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `sessionId` | path | Yes | string |  |
| `X-Group-Id` | header | No | string | Active workspace group ObjectId |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Messages array |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/chats/session/{sessionId}" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/chats/session/{sessionId}', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
