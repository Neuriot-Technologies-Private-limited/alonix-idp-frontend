# GET /chats/sessions

**[Try in API Playground](/api-playground?path=%2Fchats%2Fsessions&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/chats/sessions` |
| **Tag** | Chats |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `X-Group-Id` | header | No | string | Active workspace group ObjectId |
| `groupId` | query | No | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Sessions list |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/chats/sessions" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/chats/sessions', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
