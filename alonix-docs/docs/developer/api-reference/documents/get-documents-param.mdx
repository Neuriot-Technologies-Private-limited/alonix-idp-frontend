# GET /documents/\{id\}

**[Try in API Playground](/api-playground?path=%2Fdocuments%2F%7Bid%7D&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/documents/{id}` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `id` | path | Yes | string |  |
| `X-Group-Id` | header | No | string | Active workspace group ObjectId |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Document |
| 403 | Sensitivity or group forbidden |
| 404 |  |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/documents/{id}" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/documents/{id}', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
