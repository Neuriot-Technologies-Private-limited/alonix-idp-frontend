# POST /groups/\{groupId\}/documents/\{id\}/extract

**[Try in API Playground](/api-playground?path=%2Fgroups%2F%7BgroupId%7D%2Fdocuments%2F%7Bid%7D%2Fextract&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/groups/{groupId}/documents/{id}/extract` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `groupId` | path | Yes | string |  |
| `id` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
{
  "format": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 202 | Extraction started |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/groups/{groupId}/documents/{id}/extract" \
  -H "Content-Type: application/json" \
  -d '{
  "format": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/groups/{groupId}/documents/{id}/extract', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "format": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
