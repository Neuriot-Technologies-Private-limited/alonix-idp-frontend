# POST /documents/upload

**[Try in API Playground](/api-playground?path=%2Fdocuments%2Fupload&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/documents/upload` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `X-Group-Id` | header | No | string | Active workspace group ObjectId |

## Request body

**Content-Type:** `multipart/form-data`

```json
{
  "file": "string",
  "groupId": "string",
  "fileName": "string",
  "sensitivityLevel": "PUBLIC"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 201 | Document created |
| 401 |  |
| 402 | Quota or subscription limit |
| 403 |  |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/documents/upload" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/documents/upload', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "file": "string",
      "groupId": "string",
      "fileName": "string",
      "sensitivityLevel": "PUBLIC"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
