# POST /groups/\{groupId\}/documents/upload

**[Try in API Playground](/api-playground?path=%2Fgroups%2F%7BgroupId%7D%2Fdocuments%2Fupload&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/groups/{groupId}/documents/upload` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `groupId` | path | Yes | string |  |

## Request body

**Content-Type:** `multipart/form-data`

```json
{
  "file": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 201 | Document created |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/groups/{groupId}/documents/upload" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/groups/{groupId}/documents/upload', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "file": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
