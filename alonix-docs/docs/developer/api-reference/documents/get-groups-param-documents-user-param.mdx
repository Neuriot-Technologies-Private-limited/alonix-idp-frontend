# GET /groups/\{groupId\}/documents/user/\{userEmail\}

**[Try in API Playground](/api-playground?path=%2Fgroups%2F%7BgroupId%7D%2Fdocuments%2Fuser%2F%7BuserEmail%7D&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/groups/{groupId}/documents/user/{userEmail}` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `groupId` | path | Yes | string |  |
| `userEmail` | path | Yes | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Document list |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/groups/{groupId}/documents/user/{userEmail}" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/groups/{groupId}/documents/user/{userEmail}', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
