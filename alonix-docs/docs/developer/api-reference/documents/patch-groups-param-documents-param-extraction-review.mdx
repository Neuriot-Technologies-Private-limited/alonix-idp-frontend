# PATCH /groups/\{groupId\}/documents/\{id\}/extraction-review

| | |
|---|---|
| **Method** | `PATCH` |
| **Path** | `/api/groups/{groupId}/documents/{id}/extraction-review` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `groupId` | path | Yes | string |  |
| `id` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
"string"
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Review saved |

## Code examples

### cURL

```bash
curl -X PATCH "http://localhost:4010/groups/{groupId}/documents/{id}/extraction-review" \
  -H "Content-Type: application/json" \
  -d '"string"'
```

```javascript
const response = await fetch('http://localhost:4010/groups/{groupId}/documents/{id}/extraction-review', {
```
