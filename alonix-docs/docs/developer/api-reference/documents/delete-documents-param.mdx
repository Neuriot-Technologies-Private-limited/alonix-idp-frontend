# DELETE /documents/\{id\}

**[Try in API Playground](/api-playground?path=%2Fdocuments%2F%7Bid%7D&method=delete)**

| | |
|---|---|
| **Method** | `DELETE` |
| **Path** | `/api/documents/{id}` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `id` | path | Yes | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Deleted |
| 409 | Blocking jobs or dependencies |

## Code examples

### cURL

```bash
curl -X DELETE "http://localhost:4010/documents/{id}" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/documents/{id}', {
  method: 'DELETE',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
