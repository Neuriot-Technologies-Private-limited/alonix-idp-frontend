# POST /documents/\{id\}/ingest

**[Try in API Playground](/api-playground?path=%2Fdocuments%2F%7Bid%7D%2Fingest&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/documents/{id}/ingest` |
| **Tag** | Documents |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `id` | path | Yes | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 202 | Ingestion queued |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/documents/{id}/ingest" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/documents/{id}/ingest', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
