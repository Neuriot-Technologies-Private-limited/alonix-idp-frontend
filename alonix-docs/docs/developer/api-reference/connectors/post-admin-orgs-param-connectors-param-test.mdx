# POST /admin/orgs/\{orgId\}/connectors/\{id\}/test

SFTP connectors only.

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors%2F%7Bid%7D%2Ftest&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/admin/orgs/{orgId}/connectors/{id}/test` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |
| `id` | path | Yes | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Connection success with preview |
| 400 | Connection failed or wrong type |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/admin/orgs/{orgId}/connectors/{id}/test" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors/{id}/test', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
