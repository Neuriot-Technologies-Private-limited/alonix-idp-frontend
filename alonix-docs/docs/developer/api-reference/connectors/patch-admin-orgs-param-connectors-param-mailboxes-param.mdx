# PATCH /admin/orgs/\{orgId\}/connectors/\{id\}/mailboxes/\{mailboxId\}

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors%2F%7Bid%7D%2Fmailboxes%2F%7BmailboxId%7D&method=patch)**

| | |
|---|---|
| **Method** | `PATCH` |
| **Path** | `/api/admin/orgs/{orgId}/connectors/{id}/mailboxes/{mailboxId}` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |
| `id` | path | Yes | string |  |
| `mailboxId` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
{
  "displayName": "string",
  "status": "ACTIVE",
  "encryptedPassword": "string",
  "wrapKeyId": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Mailbox updated |

## Code examples

### cURL

```bash
curl -X PATCH "http://localhost:4010/admin/orgs/{orgId}/connectors/{id}/mailboxes/{mailboxId}" \
  -H "Content-Type: application/json" \
  -d '{
  "displayName": "string",
  "status": "ACTIVE",
  "encryptedPassword": "string",
  "wrapKeyId": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors/{id}/mailboxes/{mailboxId}', {
  method: 'PATCH',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "displayName": "string",
      "status": "ACTIVE",
      "encryptedPassword": "string",
      "wrapKeyId": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
