# GET /admin/orgs/\{orgId\}/connectors/mailboxes

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors%2Fmailboxes&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/admin/orgs/{orgId}/connectors/mailboxes` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |
| `groupId` | query | No | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Mailbox list with connector metadata |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/admin/orgs/{orgId}/connectors/mailboxes" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors/mailboxes', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
