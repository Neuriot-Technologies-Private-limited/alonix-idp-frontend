# GET /admin/orgs/\{orgId\}/mailboxes/\{mailboxId\}/ingestions

|---|---|
| **Method** | `GET` |
| **Path** | `/api/admin/orgs/{orgId}/mailboxes/{mailboxId}/ingestions` |
| **Tag** | Connectors |

## Parameters

| Name | In | Required | Type | Description |

| Status | Description |
