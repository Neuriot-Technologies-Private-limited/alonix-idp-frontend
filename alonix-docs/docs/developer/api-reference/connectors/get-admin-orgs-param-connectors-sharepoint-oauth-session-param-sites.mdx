# GET /admin/orgs/\{orgId\}/connectors/sharepoint/oauth/session/\{sessionId\}/sites

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors%2Fsharepoint%2Foauth%2Fsession%2F%7BsessionId%7D%2Fsites&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/sites` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |
| `sessionId` | path | Yes | string |  |
| `search` | query | No | string |  |

## Responses

| Status | Description |
|--------|-------------|
| 200 | tenantId and sites array |
| 404 | OAuth session expired |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/sites" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/sites', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
