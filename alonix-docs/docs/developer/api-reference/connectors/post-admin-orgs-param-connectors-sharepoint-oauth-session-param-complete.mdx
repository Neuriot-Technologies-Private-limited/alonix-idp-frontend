# POST /admin/orgs/\{orgId\}/connectors/sharepoint/oauth/session/\{sessionId\}/complete

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors%2Fsharepoint%2Foauth%2Fsession%2F%7BsessionId%7D%2Fcomplete&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/complete` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |
| `sessionId` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
{
  "name": "string",
  "siteUrl": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 201 | SHAREPOINT connector created |
| 400 |  |
| 404 | OAuth session expired |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/complete" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "string",
  "siteUrl": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors/sharepoint/oauth/session/{sessionId}/complete', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "name": "string",
      "siteUrl": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
