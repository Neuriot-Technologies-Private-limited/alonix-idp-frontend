# POST /admin/orgs/\{orgId\}/connectors

Company admin. Secrets encrypted at rest.

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fconnectors&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/admin/orgs/{orgId}/connectors` |
| **Tag** | Connectors |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
{
  "name": "string",
  "type": "EMAIL",
  "ingestHistoric": true,
  "config": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 201 | Connector created |
| 400 |  |
| 402 | Connector quota exceeded |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/admin/orgs/{orgId}/connectors" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "string",
  "type": "EMAIL",
  "ingestHistoric": true,
  "config": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/connectors', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "name": "string",
      "type": "EMAIL",
      "ingestHistoric": true,
      "config": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
