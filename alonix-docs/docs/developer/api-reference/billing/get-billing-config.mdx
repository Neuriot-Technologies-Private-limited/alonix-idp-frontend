# GET /billing/config

No auth. Used by pricing UI to show checkout availability.

**[Try in API Playground](/api-playground?path=%2Fbilling%2Fconfig&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/billing/config` |
| **Tag** | Billing |
| **Auth** | None |

## Responses

| Status | Description |
|--------|-------------|
| 200 | stripeConfigured, checkoutReady, plan price hints |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/billing/config" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/billing/config', {
  method: 'GET',
  headers: {
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
