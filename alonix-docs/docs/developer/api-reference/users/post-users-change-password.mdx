# POST /users/change-password

**[Try in API Playground](/api-playground?path=%2Fusers%2Fchange-password&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/users/change-password` |
| **Tag** | Users |
| **Auth** | Bearer JWT |

## Request body

**Content-Type:** `application/json`

```json
{
  "currentPassword": "string",
  "newPassword": "string",
  "orgId": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Password changed |
| 400 |  |
| 401 |  |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/users/change-password" \
  -H "Content-Type: application/json" \
  -d '{
  "currentPassword": "string",
  "newPassword": "string",
  "orgId": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/users/change-password', {
  method: 'POST',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "currentPassword": "string",
      "newPassword": "string",
      "orgId": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
