# POST /users/reset-password

**[Try in API Playground](/api-playground?path=%2Fusers%2Freset-password&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/users/reset-password` |
| **Tag** | Users |
| **Auth** | None |

## Request body

**Content-Type:** `application/json`

```json
{
  "email": "user@example.com",
  "token": "string",
  "newPassword": "string",
  "orgId": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Password updated |
| 400 |  |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/users/reset-password" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "user@example.com",
  "token": "string",
  "newPassword": "string",
  "orgId": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/users/reset-password', {
  method: 'POST',
  headers: {
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "email": "user@example.com",
      "token": "string",
      "newPassword": "string",
      "orgId": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
