# POST /users/onboard

**[Try in API Playground](/api-playground?path=%2Fusers%2Fonboard&method=post)**

| | |
|---|---|
| **Method** | `POST` |
| **Path** | `/api/users/onboard` |
| **Tag** | Users |
| **Auth** | None |

## Request body

**Content-Type:** `application/json`

```json
{
  "companyName": "string",
  "email": "user@example.com",
  "password": "string",
  "name": "string"
}
```

## Responses

| Status | Description |
|--------|-------------|
| 201 | Organization and admin user created |
| 400 |  |
| 409 | Duplicate user field |
| 500 |  |

## Code examples

### cURL

```bash
curl -X POST "http://localhost:4010/users/onboard" \
  -H "Content-Type: application/json" \
  -d '{
  "companyName": "string",
  "email": "user@example.com",
  "password": "string",
  "name": "string"
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/users/onboard', {
  method: 'POST',
  headers: {
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "companyName": "string",
      "email": "user@example.com",
      "password": "string",
      "name": "string"
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
