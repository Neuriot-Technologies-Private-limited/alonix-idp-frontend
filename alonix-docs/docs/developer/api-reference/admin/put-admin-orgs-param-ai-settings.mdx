# PUT /admin/orgs/\{orgId\}/ai-settings

**[Try in API Playground](/api-playground?path=%2Fadmin%2Forgs%2F%7BorgId%7D%2Fai-settings&method=put)**

| | |
|---|---|
| **Method** | `PUT` |
| **Path** | `/api/admin/orgs/{orgId}/ai-settings` |
| **Tag** | Admin |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `orgId` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
"string"
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Updated settings |

## Code examples

### cURL

```bash
curl -X PUT "http://localhost:4010/admin/orgs/{orgId}/ai-settings" \
  -H "Content-Type: application/json" \
  -d '"string"'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/orgs/{orgId}/ai-settings', {
  method: 'PUT',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify("string"),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
