# GET /admin/groups/\{groupId\}/audit-logs

**[Try in API Playground](/api-playground?path=%2Fadmin%2Fgroups%2F%7BgroupId%7D%2Faudit-logs&method=get)**

| | |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/admin/groups/{groupId}/audit-logs` |

| **Auth** | Bearer JWT |

| Name | In | Required | Type | Description |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Scoped audit logs |

## Code examples

### cURL

```bash
curl -X GET "http://localhost:4010/admin/groups/{groupId}/audit-logs" \
  -H "Authorization: Bearer <token>"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/groups/{groupId}/audit-logs', {
  method: 'GET',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
