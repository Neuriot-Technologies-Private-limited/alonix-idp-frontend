# PUT /admin/groups/\{groupId\}/document-sensitivity-policy

**[Try in API Playground](/api-playground?path=%2Fadmin%2Fgroups%2F%7BgroupId%7D%2Fdocument-sensitivity-policy&method=put)**

| | |
|---|---|
| **Method** | `PUT` |
| **Path** | `/api/admin/groups/{groupId}/document-sensitivity-policy` |
| **Tag** | Admin |
| **Auth** | Bearer JWT |

## Parameters

| Name | In | Required | Type | Description |
|------|-----|----------|------|-------------|
| `groupId` | path | Yes | string |  |

## Request body

**Content-Type:** `application/json`

```json
{
  "enabledDocumentSensitivityLevels": [
    "PUBLIC"
  ]
}
```

## Responses

| Status | Description |
|--------|-------------|
| 200 | Updated group |

## Code examples

### cURL

```bash
curl -X PUT "http://localhost:4010/admin/groups/{groupId}/document-sensitivity-policy" \
  -H "Content-Type: application/json" \
  -d '{
  "enabledDocumentSensitivityLevels": [
    "PUBLIC"
  ]
}'
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:4010/admin/groups/{groupId}/document-sensitivity-policy', {
  method: 'PUT',
  headers: {
    'Authorization: Bearer <token>',
    'Content-Type: application/json',
  },
  body: JSON.stringify({
      "enabledDocumentSensitivityLevels": [
          "PUBLIC"
      ]
  }),
});

const data = await response.json();
if (!response.ok) throw new Error(data.message || response.statusText);
console.log(data);
```
