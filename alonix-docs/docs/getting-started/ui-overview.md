# UI Overview

## Overview

Alonix uses a consistent layout across all pages: a top navigation bar for global actions, a sidebar for section navigation, and a main content area. Understanding this layout helps you move quickly between documents, AI Chat, admin tools, and settings.

## Purpose

Orient new users so they know where to find features without hunting through menus.

## Prerequisites

- Logged in to Alonix — see [Logging In](/docs/getting-started/logging-in)
- Access to at least one workspace

## Step-by-Step Instructions

### 1. Top navigation bar

The top bar typically includes:

| Element | Purpose |
|---------|---------|
| **Logo / Home** | Return to Dashboard |
| **Workspace switcher** | Change active Group/workspace |
| **Search** (if shown) | Quick document search |
| **Notifications** | System alerts and updates |
| **Profile menu** | Profile, settings, log out |

[Screenshot – Top navigation bar with workspace switcher and profile menu annotated]

### 2. Sidebar navigation

The left sidebar lists main sections. Available items depend on your role:

| Section | Typical access |
|---------|----------------|
| Dashboard | All users |
| Groups / Workspaces | Admins; view varies for Search Users |
| Users | Company Admin, Group Admin |
| Documents | All users in workspace |
| AI Chat | All users in workspace |
| Connectors | Group Admin, Company Admin |
| Reports | All users (export permissions may vary) |
| Activity Logs | Admins; limited view for Search Users |
| Org Settings | Company Admin |
| Billing | Company Admin (SaaS only) |

### 3. Main content area

The center of the screen shows the active page—tables, forms, document viewers, chat panels, or charts. Breadcrumbs at the top help you track location within nested views.

### 4. Profile menu

Click your avatar or name to access:

- **Profile** — name, email, password, preferences
- **Log out** — end your session

Company Admins may also reach org-level settings from here or the sidebar.

### 5. Role-based visibility

:::note What you see is intentional
If a menu item is missing, your role likely does not include that permission. See [Users and Roles](/docs/user-guide/users-and-roles).
:::

## Expected Results

You can identify:

- Where to switch workspaces
- How to reach Documents, AI Chat, and Reports
- Where profile and logout live
- Why some menu items may be hidden for your role

## Tips

- The workspace switcher is the most important control—check it before every upload or chat session.
- Collapse the sidebar on smaller screens using the menu toggle (hamburger icon).
- Use browser zoom (100–125%) if tables feel cramped on laptop displays.

## Best Practices

- Develop a habit: **workspace first, then action**.
- Pin frequently used sections mentally: Documents for files, AI Chat for questions, Activity Logs for audits.
- Learn keyboard focus order if your org requires accessibility compliance—tab through forms logically.

## Common Mistakes

- Uploading documents while the wrong workspace is selected.
- Looking for Billing or Org Settings as a Search User—these are admin-only.
- Assuming missing UI is a bug—confirm role permissions first.

## Troubleshooting

| Issue | Action |
|-------|--------|
| Sidebar empty or minimal | Confirm workspace access with admin. |
| Page layout broken | Update browser; see [System Requirements](/docs/getting-started/system-requirements). |
| Cannot find a feature | Check [User Guide](/docs/user-guide/dashboard) index or [FAQ](/docs/faq/). |
